PROPANE INTELLIGENCE — PARTNER PROTOTYPE

HOW TO VIEW
1. Unzip the folder.
2. Double-click index.html.
3. Use the left navigation to move among pages.
4. The My Company, Logistics Optimizer, and Customer Profitability pages contain interactive demo inputs.

WHAT THIS IS
A static, no-backend product prototype intended for internal business discussion. All figures are illustrative demo values.

GITHUB PAGES
These files can be uploaded directly to a GitHub repository with GitHub Pages enabled. No build process or external dependencies are required.
