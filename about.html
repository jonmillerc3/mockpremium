Production architecture later

Keep GitHub

Source control, development history, deployment workflows and collaboration. GitHub Pages is ideal for this no-backend prototype.

Move customer data off GitHub Pages

Production application would use secure authentication, a proper database, encryption, billing, backups, company-level access controls and audit logging.
Trust framework for private retailer data

Bilateral NDA

Protect proprietary operating and customer information.

Data isolation

A retailer sees only its own private data. Cross-company benchmarks are anonymized and aggregated.

Customer ownership

Contract language should clearly state ownership, retention, deletion and permitted uses of uploaded data.
